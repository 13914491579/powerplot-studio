# PDF Chinese fallback font

`NotoSansSC-Regular.ttf` is a static weight-400 instance of Noto Sans SC.
Source: https://github.com/notofonts/noto-cjk/raw/main/Sans/Variable/TTF/Subset/NotoSansSC-VF.ttf
License: SIL Open Font License 1.1, see OFL.txt.

The static instance was generated using fontTools 4.66.1 (`instantiateVariableFont`, wght=400).
It is loaded from this application's own static assets, never from a third-party font service.
The PDF embeds only the used glyph subset. Times New Roman system files are not distributed.

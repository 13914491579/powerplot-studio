# PowerPlot Studio 2.4 三维科研绘图

二维解析、八种网格、跨文件组合、精细 SVG 图例、IEEE 尺寸及 PNG/SVG/矢量 PDF/ZIP 管线保留不变。3D 使用单独按需加载的 Plotly gl3d 3.7.0（MIT），不替换二维引擎。2D 和 3D 共用原始 Dataset，配置独立，会话内切换保留。

## 瀑布图

导入 TXT/CSV → 3D 绘图 → 三维瀑布图 → 勾选信号。可跨文件、同名文件，内部使用 UUID+列号。X 为信号自己的原始时间，Y 为工况坐标，Z 为原始数值。沿 Y 轴排列，首版不提供其他排列轴。

自动模式：第 i 条坐标为 起始值 + i×间隔（i 从 0 开始）；上移改变顺序。手动模式逐条输入数值，允许非等间距。显示标签单独保存，与数值无关。可修改各曲线名称、颜色、线宽、显示、图例；首版固定实线。

## 轨迹图

选择三维轨迹图，为 X/Y/Z 分别选择数据源。要求时间列标识与每一个时间数值相同；不同文件也能使用。时间起点、采样数量、时间间隔或单位标识不同则阻止生成，不按索引强行拼接，也不提供未经验证的插值。轨迹样式使用第一条勾选曲线；未勾选时采用默认样式。

## 交互、排版与导出

鼠标旋转、滚轮缩放，工具栏切换旋转/平移；提供默认/正视/侧视/俯视和自动适配。可编辑相机 eye/center/up；交互后的相机存入独立 3D 状态，导出等待绘图队列完成并使用当前场景。

X/Y/Z 标题、单位、范围、主刻度间隔（0 自动）、网格与字号独立可编辑。画布使用 inch/mm，PNG 使用当前物理尺寸×DPI，写入 DPI 元数据，提供 300/600 DPI 和自定义值。

3D 只导出高清 PNG。WebGL SVG 通常嵌入栅格绘图区，不提供“全矢量 SVG/PDF”误导入口；二维矢量导出完整保留。未来可将经过相机投影与深度排序的三维折线重建成 SVG 路径，但遮挡、裁切、文字布局与透明度处理需要单独验证，本版不自建渲染器。

## 限制

需要 WebGL 浏览器与可用显卡/软件渲染；不做降采样、插值、排序、滤波或原始数组修改。百万点尚未压力验收，选择大量曲线可能阻塞绘图线程。刷新不持久化；不支持 2D/3D 混排、3D 子图和 3D 矢量导出。背景和默认字体为科研简洁样式；复杂标题和小画布应先核对预览。

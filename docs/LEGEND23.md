# 2.3 精细图例排版

在“图例”面板将排版系统切换为“精细 SVG 图例”。兼容图例保留已有行为；自动/手动模式共用样式并保留手动坐标。

- 自动：水平/垂直间距、线段长度、线段文字间距均为 pt；横向/纵向、自动换行、每行最大项目数（0 自动），左/中/右/均匀分布。均匀分布先测量实际 SVG 文字宽度再分配剩余空间。
- 手动：拖动单个图例实时更新，松开保存；X/Y 精确输入。相对于对应绘图区左下角，X 向右、Y 向上，坐标定位图例左上角。鼠标拖动按 4 CSS px 吸附，阻止波形缩放事件。点击或键盘 Enter/空格切换曲线显示。
- 每项恢复默认及恢复整组自动布局。手动项目按稳定曲线/组合实例 ID 保存，切换画布物理尺寸保持归一化坐标；删除文件清理其引用。
- 独立子图：选择“当前子图独立图例”，切换当前编辑子图设置，不影响其他子图。未启用精细模式的子图继续使用原生图例。
- PNG、SVG、PDF、ZIP 复用同一 SVG 图例层快照，保留物理尺寸与 DPI；不使用整图截图 PDF。文字通过 textContent 写入，名称不是 HTML。

限制：手动位置可能遮挡曲线；边缘裁切会提示，长文字或拥挤布局应增大画布、改为纵向或减小字号。外置布局空间预留采用保守宽度估算，实际项目分布使用浏览器字体测量。PDF 系统/中文字体替代限制沿用 2.2，投稿前仍需核对最终字体。暂不提供跨项目对齐线、任意富文本或刷新持久化。

# 后续开发规划

第二阶段现已完成。下一阶段经确认后再实现持久化与大数据性能优化。

## 第二阶段：已实现

1. 论文 / 自由编辑模式共用同一原始数据与曲线样式。
2. IEEE 单栏、双栏与自定义物理尺寸，按 mm / inch 和 DPI 明确换算 PNG 像素；标注实际模板参数供用户核对期刊要求。
3. 完整坐标范围、刻度、字体、字号、图例位置、线宽与线型编辑，以及多子图布局。
4. 使用 `jsPDF` + `svg2pdf.js` 转换 SVG，已验证中文字体嵌入、物理页面、矢量曲线与零图片。
5. 引入 JSZip，批量导出多个图表；统一命名、冲突处理、进度提示和异常处理。

之前 MATLAB 脚本的 88.9 × 110 mm 三子图、原始时间与单位保留、印刷字号经验可作为参考。其固定三文件、两列数据和相同时间轴限制不迁移到本项目。

## 第三阶段：项目与性能

1. 定义带版本号的 JSON schema；区分仅样式的模板、引用文件的配置与包含原始数据的完整项目。
2. 保存文件与曲线映射、原始数组（仅完整项目）、名称、颜色、显示状态、轴、字体、尺寸、图例、网格和绘图模式。
3. 配置恢复时校验格式版本、数组长度、数字有效性、文件匹配冲突，提供明确提示。
4. 在第二阶段格式同步基础上增加项目恢复后的文件与曲线匹配，不改写原始数据。
5. 大文件采用分块读取 / TypedArray / 可转移缓冲区，减少复制与峰值内存。
6. 预览根据时间可视范围分桶，保留各桶首尾与最小 / 最大值及其原始时间、原始顺序；不能只取平均。导出根据物理尺寸和像素分辨率选择策略并明确告知用户。
7. 测试几十万到百万点、不同采样间隔、单点极值、窄暂态、多个文件、缩放后重采样和长时间会话。

PSCAD `.out` / `.inf` 另设适配器，通过 `DataAdapter` 返回统一数据模型，并使用真实文件验证编号、通道名称、单位和时间映射。

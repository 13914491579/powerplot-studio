# PowerPlot Studio 2.5 三维页面与排版

沿用统一顶部导入与 2D/3D 导航。左侧保留文件管理；3D 画布与分组设置并排，预览固定，设置面板独立滚动和折叠。顶部“下载 3D PNG”及最终像素数始终可见，底部“画布与导出”仍保留旧下载按钮。

## 标准科研视角

新建默认 eye=(1.6,-1.6,1.2)、center=(0,0,0)、up=(0,0,1)，不反转 X 轴或改变原始采样顺序。“标准科研视角”及“恢复默认视角”恢复这一视角；保留旧“默认三维”、正视、侧视、俯视。测试从 WebGL 实际视图矩阵投影归一化 X 两端，验证屏幕横向差值为正，且真实 PSCAD 截图人工核对时间增大方向。旋转后可能改变屏幕方向，可随时恢复。

## 图例

独立“图例”面板默认启用精细 SVG 图例，复用 2.3 的排版和稳定 ID 机制，支持横纵排列、左中右/均匀分布、间距、线段长度、文字间距、字号、区域和单项精确定位/拖动。单条名称和图例开关在“数据与曲线”，总开关在图例面板。

坐标基准为画布扣除边距后的二维矩形，X 右、Y 上，项目左上角定位；与 XYZ 场景及相机独立。点击图例切换曲线显示。三维相机旋转不移动图例；格式变化不重置相机。手动图例可遮挡数据，边缘风险有提示。

WebGL 导出不会自动保留任意 DOM 层：本版先导出当前 WebGL 场景 PNG，再将当前 SVG 图例快照按同一坐标和 DPI 合成到 PNG。没有重复绘制原生图例。保持图例文字/颜色/线段/坐标与预览一致，最终仍为 PNG 栅格图，不宣称矢量 PDF。

## 场景、尺寸与导出

“画布与导出”提供 IEEE 单栏 3.5×3.2 inch、双栏 7.16×4.5 inch、自定义 inch/mm、300/600/自定义 DPI，以及最终像素数。场景 domain 比例、XYZ aspectratio、上方留白、相机距离和大尺寸预览倍数分别控制布局。大尺寸预览重新设置 Plotly 渲染尺寸并同步字号/图例比例，非 CSS 不等比拉伸；导出始终采用物理尺寸×DPI，与预览倍数无关。

自动适配恢复自动轴范围与标准视角。相机更新只修改 scene.camera，不覆盖坐标轴。2D/3D 各自保留当前会话配置；原有二维八布局、跨文件组合、精细图例、IEEE 及 PNG/SVG/矢量 PDF/ZIP 保持。

限制：极端密集图例、长中文和近距离相机可能裁切或遮挡，应扩大画布、调留白/字号/距离并检查预览。单项坐标输入未保存时显示初始建议值；设置后按输入定位。不提供三维 SVG/PDF、刷新持久化或百万点性能保证。三维数据规则与严格轨迹时间匹配沿用 2.4。

# PowerPlot Studio 2.1 网格多子图

沿用 2.0 原始解析器及统一的 Plotly → SVG → PNG / PDF 导出管线；不改写输入时间或信号数组，不插值、不平滑、不重新采样。每个数据文件图表及合并图表仍有独立配置。

## 使用步骤

1. 导入 TXT / CSV，在右侧“子图”点击网格缩略图。第一个数字为行数，第二个数字为列数。
2. 点击“顺序分配曲线到子图”，或在每条曲线的“分配子图”下拉框中指定位置。同一位置可以有多条曲线；曲线颜色、名称、线型、线宽、显示及图例开关仍在“曲线”中编辑。
3. 用“当前编辑子图”选择对象。在“坐标轴”编辑该子图的 X/Y 标题、单位、范围、主刻度、小数及网格。左侧 X 标题快捷输入作用于所有子图；右侧详细标题作用于当前子图。
4. “X 轴范围同步”可选各自独立、全部同步、按列同步。同步采用组内第一张图的手动范围或组内所有原始时间数组的并集，并通过 Plotly `matches` 联动缩放。全部同步的范围源为子图 1；按列同步为本列最上方子图。其他子图的独立范围仍保存，切回独立模式恢复生效。标题、单位、刻度样式不随范围源覆盖。
5. “隐藏非底部 X 标题与刻度”独立控制标签；同步范围不会强制隐藏标签。独立模式始终显示所有 X 标签。横向和 2×2 默认各自独立且显示全部标签；纵向默认全部同步且只显示最底部 X。
6. 在“子图”编辑当前编号、字号、0–1 的相对 X/Y 位置及可见状态。多图默认 `(a)`–`(d)`，按从左到右、从上到下编号。单图不绘制子图编号。
7. “图例”选择“当前子图独立图例”，分别设置位置、横纵排列、字号、边框、不透明度、可见状态。默认在绘图区上方；左侧“显示图例”为总开关。手动图例位置为各子图绘图区的相对坐标，可能覆盖数据，需检查预览。
8. 设置水平/垂直附加间距、轴标题间距、刻度与标签间距；“字体与排版”编辑四周最小边距和整体字体。布局同时为各列的 Y 标题/刻度及各行 X 标签/图例预留空间，间距不会导致输入数据改变。
9. 导出整个组合图，三种格式使用同一布局与当前显示窗口。导出尺寸就是当前实际尺寸，不会偷偷切换推荐宽高。

## 布局推荐尺寸

默认字体（轴 9 pt、刻度 8 pt）、垂直附加间距 14 pt 下：

| 布局（行×列） | 宽 / inch | 高 / inch | 默认 X 模式 |
| --- | --- | --- | --- |
| 1×1 | 3.5 | 2.2 | 单图 |
| 1×2 | 7.16 | 2.7 | 独立、全部显示 |
| 2×1 | 3.5 | 3.73 | 同步、底部显示 |
| 1×3 | 7.16 | 2.7 | 独立、全部显示 |
| 3×1 | 3.5 | 5.51 | 同步、底部显示 |
| 2×2 | 7.16 | 3.73 | 独立、全部显示 |
| 1×4 | 7.16 | 2.7 | 独立、全部显示 |
| 4×1 | 3.5 | 7.29 | 同步、底部显示 |

多行推荐高度根据行数、轴标题字号、刻度字号及垂直间距计算；不是全部使用固定高度。这些尺寸是可编辑起点，不保证适合所有期刊。横向四图若需要更多主刻度或较长标题，建议自定义更宽画布。

初始处于“尺寸随布局推荐”状态。手动修改宽、高、宽高比，或主动选择任意模板后，进入手动状态；后续布局切换保留该尺寸。切换 mm / inch 只做等长换算，修改 DPI 不解除手动状态。“恢复布局推荐尺寸”重新应用当前布局推荐值并启用随布局推荐。过小画布会阻止绘图/导出并明确提示扩大尺寸或缩小字号，配置不被自动覆盖。

## 配置保留与限制

- 始终保留四个子图的轴、编号和图例配置；减少数量不会删除。所属子图超出当前数量的曲线暂不显示，界面明确提示；恢复数量后原分配生效，不把它们静默移动到最后一张图。也可手动移动到可见子图。
- 共享范围期间，其他子图的不同手动范围暂不生效。共享不统一采样，各曲线继续使用自己的时间数组。
- 当前曲线一次属于一个子图；可以移动或叠加，不支持同一信号同时复制到多个子图。曲线样式继续跨分别/合并模式共享，图表布局配置各自独立。
- 推荐尺寸和自动空间预留针对普通科学标签；很长的文字、密集刻度、多条独立图例需增加尺寸或减小字号。图内编号/图例可能遮挡数据，位置可手动调整。
- 项目仍无持久化；刷新后重新导入/配置。百万点交互降采样留待后续阶段。PDF 标准拉丁字体替代与中文字体限制沿用 2.0。

# PowerPlot Studio 2.2 跨文件自由组合

## 使用

1. 导入多个 TXT / CSV，点击左侧“组合绘图”。原有分别/合并绘图的配置与曲线样式保留。
2. 在“子图”选择八种网格布局之一，选择“当前编辑子图”。展开文件并勾选信号，一张子图可包含多个文件；同一信号可在多个子图勾选。
3. 每个文件可“全选此文件信号”，也可“清空当前子图分配”。“曲线”只编辑当前子图选中的实例，其颜色、名称、线宽、线型、显示与图例开关独立。所属子图控件用于移动实例；若目标已有该信号，会合并为一个实例并采用移入样式。
4. “按文件自动分配”按导入顺序将每个文件全部信号放到一张子图。“按信号自动分配”按完整表头的 NFKC、首尾空白、连续空白与大小写规范化匹配，保留原始表头显示；单位仍是匹配键的一部分，不推测别名或进行单位换算。
5. 自动分配先展示所有候选及来源列，再“确认应用分配”。同一文件重名列、无表头的自动名称不会跨文件自动归类；未匹配的名称保留独立候选并提示。候选多于子图时，按钮禁用，需增加布局、手动勾选，或明确勾选“仅分配前 N 组”。未分配文件的数据仍在数据源列表。
6. 快捷分配替换可见子图成员，保留隐藏槽位及实例样式；减少/恢复布局时不删除成员。删除文件只清理该文件的源引用与组合实例样式，不改变其他文件的轴或布局。
7. 各子图坐标轴、范围、单位、刻度、编号和图例继续按 2.1 规则编辑。不同物理量可以叠加，但 Y 轴仍为一个线性坐标系，须主动核对标题与单位；不会自动归一化、换算或生成双 Y 轴。
8. PNG / SVG / 矢量 PDF 导出整张组合画布；“全部图表打包 ZIP”在组合模式包含这一张组合图。分别绘图模式仍批量导出多个文件图表。

## 数据模型与准确性

文件由 UUID 识别，信号 ID 为文件 UUID + 原始列索引，实例 ID 由信号 ID + 子图槽位组成。同名文件在组合列表/图例显示导入序号；序号随列表位置变化，但内部 ID 不变。同一子图对一个源最多创建一个实例。

成员映射与实例样式独立于原有样式和绘图配置。绘图仅构造 Plotly trace 视图，每个实例直接引用原始时间/数值数组，无插值、排序、平滑、重采样或复制采样数组。解析器只新增“是否有表头”元数据，数值规则不变。

三种导出继续共用现有 Plotly → SVG → PNG / svg2pdf 管线。推荐尺寸、手动尺寸保护、过小画布提示、X 范围同步与标签显隐继续沿用 2.1；独立图例横排超出子图宽度时自动纵排，避免跨列重叠；图例很多时需扩大画布或调整字号。原始时间单位不同的文件不会转换单位，共享 X 前需自行核对。

## 当前边界

配置仅保留在当前浏览器会话内，刷新后需重新导入。最多四张子图；匹配不处理物理量语义或近似拼写。PDF 字体替代及大型 SVG 性能限制沿用原版。完整回归执行 `pnpm.cmd check`，新增测试为 `src/composition.test.ts` 与 `e2e/composition.spec.ts`。

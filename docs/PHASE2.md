# PowerPlot Studio 2.1 功能与验收

## 配置与数据

每个独立文件图表、合并图表分别保存内存中的 `PlotConfig`，曲线身份仍为文件 ID + 信号列号。没有替换原解析器，也没有通过固定采样周期重建时间。切换模板、子图和范围只修改绘图参数，原始数组继续被直接引用。

“论文绘图 / 自由编辑”共用同一数据和配置。两种模式均允许修改参数；选择 IEEE 模板时重置论文默认字体、边距、图例和线宽，保留数据、名称、颜色与坐标范围。模式切换本身不会丢弃手动设置。

## 编辑项目

| 分类 | 内容 |
| --- | --- |
| 模板 | 单栏 3.5 inch、双栏 7.16 inch、自定义 mm / inch、宽高与宽高比、默认线宽 |
| 坐标轴 | 独立 X / 每个 Y、自动 / 手动范围、自动 / 间隔 / 精确数量刻度、小数位、网格颜色宽度线型、轴线颜色宽度 |
| 曲线 | 名称、颜色、可见、独立线宽、实 / 虚 / 点 / 点划线、是否列入图例、所属子图 |
| 字体与排版 | Times New Roman / Arial / Courier New / Noto Sans SC、各字号、文字颜色、图表标题与最小边距 |
| 图例 | 显示、上下左右 / 图内 / 手动归一化坐标、横纵排列、字号、边框、背景不透明度 |
| 子图 | 八种二维网格、独立 X/Y、按列/全部范围同步、独立图例与编号、推荐尺寸及手动保护 |
| 导出 | 300 / 600 / 自定义 DPI，当前图 PNG / SVG / PDF，当前模式全部图表 ZIP |

轴标题留空自动命名。手动范围必须最小值小于最大值；刻度间隔必须大于零，拒绝一次生成超过 1000 个主刻度；手动数量为 2–100。隐藏某条曲线不会删除数据，也可保留该曲线的灰色图例；关闭曲线“显示图例”可独立删除图例项。

2.1 中每个子图拥有独立 X/Y 配置。范围同步与标题/刻度显隐分离；横向与网格默认独立，纵向默认共享并仅底部显示 X。完整步骤与尺寸规则见 [网格说明](GRID21.md)。

## 一次浏览器验收路线

1. 运行 `pnpm.cmd dev`，打开 `http://127.0.0.1:5173/` 并刷新旧页面。
2. 点击“加载示例数据”，查看 501 点真实电流与三信号非等间隔示例；切换分别 / 合并模式，确认暂态尖峰保留。
3. 在右侧选择三信号图，打开“模板”，切换单栏 / 双栏；单栏宽度为 3.5 inch，换为 mm 后为 88.9 mm。
4. 在“坐标轴”关闭 X 自动范围，设为 1.95–2.08；选择手动间隔 0.02、小数 3 位。切换 Y1，独立设置范围 / 数量。
5. 在“曲线”展开任意曲线“样式”，修改线型、线宽、颜色、名称和图例开关。
6. 在“子图”选择上下双 / 三图，再点“顺序分配曲线到子图”；也可在曲线样式中手动选择子图。检查每个 Y 轴与底部共享 X。
7. 在“字体与排版”修改字号、标题和边距；在“图例”试验外置位置与横纵排列。过小尺寸会提示调整，用户手动位置需检查是否遮挡。
8. 回到单图，设 3.5 × 2.2 inch、600 DPI，下载 PNG，检查 2100 × 1320。下载 SVG / PDF 放大查看，曲线与文字清晰；PDF 页应为 252 × 158.4 pt。
9. 分别模式下选择源图，改变字体 / 尺寸，再“应用格式到其他图表”，确认目标名称 / 颜色 / 范围保留。勾选颜色 / 范围后重试。范围同步使用各子图当前显示窗口（包含缩放后的范围）。
10. 在“导出”选择 PNG / SVG / PDF 分别导出全部 ZIP，检查文件数与名称，不同文件同名时自动加 `-2`、`-3`。

## 导出技术与边界

PNG、SVG 和 PDF 基于相同的物理布局快照，暂停中的字体 / PDF 工作不会重新读取后来改变的预览范围。PNG 不用网页截图，精确栅格化 SVG 并写入 DPI 元数据。PDF 不用 PNG，SVG 路径、文字和剪裁直接转换。

2.0 历史验收曾检查三子图中文 PDF：252 × 324 pt，中文可提取，含字体子集、矢量路径、零图片，使用 Poppler 渲染后核对图例、轴标签和波形，无裁切。标准字体与系统 Times New Roman / Arial 存在替代关系；中文混排采用 Noto，正式投稿前检查目标系统显示效果。

样式同步以信号列的顺序匹配线宽、线型和子图分配；目标曲线多于源曲线时循环使用源样式。默认保留目标可见状态、图例开关、曲线名称、颜色、轴标题、图表标题和坐标范围，同步字体、字号、物理尺寸、DPI、轴线 / 刻度 / 网格、图例、布局和线条样式。可选颜色、当前显示范围同步。合并模式只有一张图，应回到分别模式同步其他图表。

未加入登录、存储、收费、数据库、远程数据上传、项目 JSON、PDF 任意字体上传或百万点降采样。刷新页面后的数据和配置仍需重新导入 / 编辑，项目持久化留到第三阶段。
